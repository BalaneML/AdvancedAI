# AdvancedAI

## Rules
- 共通のBaselineコードを変更する場合はPull Requestを作る。
- 各改良案は別Branchで実装する。
- 実験結果（lerder board 方式をgoogle sheetsで管理）にはGit Commit IDを記録する。
- 採用するモデルは全員で確認する。最後に確認した人が該当remote branchをremoteのmain branchにmerge
- 採用しないモデルも比較実験で使う可能性あるのでremote branchとして残し削除しない。

## PTINet

共通BaselineのQuickstart・評価方法は [ptinet/README.md](ptinet/README.md) を参照。mainの変更は従来どおりPRとメンバー審査を経る。
